# FitLog 🏋️

A dark, no-nonsense gym companion. Browse a workout library, lock lifts into today's plan, and save others for later.

**Live demo:** https://fitlog-omega-five.vercel.app/

## Technologies Used
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify
- React Icons

## Features
1. Fully responsive on mobile, tablet, and desktop
2. Workout library fetched live from an API, with a loading spinner
3. Detailed workout page with specs and step-by-step instructions
4. Today's Plan and Saved lists with live navbar counters
5. Mark as done and remove actions with toast notifications
6. Sort your lists by duration, calories, or rating
7. Plan and saved data persist in localStorage
8. 5-lift daily cap and a custom 404 page

## Run Locally
```bash
npm install
npm run dev
```
